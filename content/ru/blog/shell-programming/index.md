На этой неделе выполнял лабораторную работу №12 — расширенное программирование в командном процессоре ОС UNIX. Работа была направлена на написание сложных bash-скриптов с использованием управляющих конструкций и циклов.

## Цель работы

Изучить основы программирования в оболочке ОС UNIX. Научиться писать более сложные командные файлы с использованием логических управляющих конструкций и циклов.

## Задание 1: Механизм семафоров

Написал командный файл, реализующий упрощённый механизм семафоров. Скрипт:

- в течение времени `t1` дожидается освобождения ресурса, выводя соответствующие сообщения
- получив доступ, использует ресурс в течение времени `t2 ≠ t1`, сообщая об этом в терминал

Скрипт был запущен в одном терминале в фоновом режиме с перенаправлением вывода в другой терминал (`> /dev/tty#`). Во втором терминале тот же скрипт был запущен в обычном режиме. Это наглядно показало, как два процесса конкурируют за общий ресурс.

Программа была доработана для поддержки взаимодействия трёх и более процессов через один семафор.

## Задание 2: Реализация команды `man`

Реализовал команду `man` в виде командного файла. Скрипт:

- принимает название команды в качестве аргумента командной строки
- ищет соответствующий архив в каталоге `/usr/share/man/man1/`
- если файл найден — выводит справку через `less`
- если файл не найден — выводит сообщение об отсутствии документации

## Задание 3: Генератор случайных букв

С помощью встроенной переменной `$RANDOM` (псевдослучайные числа в диапазоне 0–32767) написал скрипт, генерирующий случайную последовательность букв латинского алфавита. Буква вычислялась по формуле:

```bash
code=$(( RANDOM % 26 + 65 ))
letter=$(printf "\\$(printf '%03o' $code)")
```
