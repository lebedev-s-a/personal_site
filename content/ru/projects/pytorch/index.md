Разработка персонального академического сайта на платформе Hugo Blox с размещением на GitHub Pages — индивидуальный проект в рамках курса «Операционные системы» (РУДН, 1 курс, направление 02.03.00 Компьютерные и информационные науки). Руководитель: профессор Кулябов Д. С.

<!--more-->

## О проекте

Цель проекта — создать полноценный персональный академический сайт, охватывающий все аспекты профессионального профиля: биографию, навыки, опыт, достижения, научные ссылки и публикации. Сайт построен на генераторе статических страниц **Hugo** с темой **Hugo Blox** (Academic), размещён на **GitHub Pages** и поддерживает два языка — русский и английский.

Проект реализован поэтапно: каждый этап добавлял новый блок функциональности и сопровождался тематическим постом.

---

## Этап 1. Размещение заготовки сайта на GitHub Pages

На первом этапе было установлено необходимое программное обеспечение: Hugo Extended, Git, а также настроена локальная среда разработки. Скачан шаблон темы Hugo Blox Academic и размещён в репозитории на GitHub. Настроен параметр `baseURL` в конфигурационном файле `config.yaml` — указан адрес будущего сайта в домене `github.io`. Репозиторий подключён к GitHub Pages через ветку `gh-pages` с автоматической публикацией средствами GitHub Actions. После первого деплоя сайт стал доступен по публичному адресу.

**Пост этапа:** пост по прошедшей неделе — первые шаги с Hugo и GitHub Pages.

---

## Этап 2. Добавление данных о владельце сайта

На втором этапе сайт был наполнен персональной информацией. В файле `content/authors/admin/_index.md` размещена фотография владельца и заполнены все основные поля профиля:

- **Фотография** — загружен файл `avatar.jpg` в папку профиля; имя и должность отображаются на главной странице.
- **Biography / Professional Summary** — добавлено краткое описание: студент направления «Компьютерные науки» РУДН, изучающий программирование, архитектуру компьютеров и операционные системы.
- **Interests** — перечислены интересы: программирование на Python и C++, компьютерные технологии, веб-разработка, изучение иностранных языков.
- **Education** — добавлена запись о бакалавриате: направление «Компьютерные науки», РУДН, с сентября 2025 года по настоящее время.

Созданы два поста: еженедельный отчёт о работе с сайтом и тематический пост **«Управление версиями. Git»** — введение в систему контроля версий, основные концепции, принцип работы, преимущества использования в учебных и рабочих проектах.

---

## Этап 3. Добавление достижений

На третьем этапе заполнены блоки, отражающие профессиональный профиль владельца:

- **Skills** — добавлены технические навыки: языки программирования (Python, C++, Bash), инструменты (Git, Linux, LaTeX, Pandoc), уровни владения представлены в виде шкал.
- **Experience** — добавлена информация об опыте: учебные проекты, лабораторные работы по операционным системам, работа с командной строкой Linux.
- **Accomplishments** — добавлены достижения: прохождение курса на Stepik по основам Linux, успешное прохождение цикла лабораторных работ по ОС.

Тематический пост этапа — **«Язык разметки Markdown»**: история создания, синтаксис заголовков, списков, кода, таблиц и ссылок; применение Markdown в академических документах и на платформах Hugo и GitHub.

---

## Этап 4. Добавление научных и библиометрических ссылок

На четвёртом этапе выполнена регистрация на ключевых научных платформах и размещение ссылок в профиле сайта в блоке `social`:

| Платформа | Назначение |
|-----------|-----------|
| **eLibrary** | Российская научная электронная библиотека |
| **Google Scholar** | Поиск академических публикаций |
| **ORCID** | Уникальный идентификатор исследователя |
| **Mendeley** | Менеджер библиографии и PDF |
| **ResearchGate** | Социальная сеть для учёных |
| **Academia.edu** | Платформа для обмена академическими работами |
| **arXiv** | Препринты по точным наукам и CS |
| **GitHub** | Репозитории учебных и личных проектов |

Тематический пост этапа — **«Создание презентаций»**: сравнение инструментов (PowerPoint, Google Slides, Beamer/LaTeX), описание рабочего процесса создания презентаций через Pandoc и тему Metropolis с шрифтами IBM Plex.

---

## Этап 5. Добавление проектов и дополнительных элементов

На пятом этапе на сайте оформлены записи для персональных проектов в разделе `content/project/`:

- **Лабораторные работы по ОС** — цикл из 14 работ по Unix/Linux (командная строка, файловая система, права доступа, текстовые редакторы vi и Midnight Commander).
- **Индивидуальный проект — данный сайт** — описание этапов разработки академического сайта на Hugo.

Тематический пост этапа — **«Языки научного программирования»**: обзор Python, R, Julia и MATLAB; сравнение экосистем для научных вычислений, визуализации данных и написания воспроизводимых исследований.

---

## Этап 6. Двуязычный сайт на GitHub

Заключительный этап — добавление поддержки двух языков. В конфигурации Hugo активированы два языка (`ru` и `en`), созданы папки `content/ru/` и `content/en/` с параллельными версиями всех страниц. Переключатель языка отображается в шапке сайта. Все ключевые разделы переведены: биография, интересы, образование, навыки, описания проектов. Оба поста этапа — еженедельный отчёт и тематический — написаны на русском и английском языках одновременно.

## Стек технологий

| Инструмент | Роль |
|-----------|------|
| **Hugo Extended** | Генератор статического сайта |

| **GitHub Actions** | Автоматический деплой при push |
| **Markdown** | Язык разметки контента |
| **Git** | Управление версиями исходников сайта |

## Итог

За шесть этапов создан полноценный персональный академический сайт: от пустой заготовки до двуязычного ресурса с профилем, проектами, публикациями и научными ссылками. Проект дал практику работы с Hugo, GitHub Actions, Markdown и системой контроля версий Git в контексте реального публичного продукта.
